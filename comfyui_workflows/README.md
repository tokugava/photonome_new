# ComfyUI Workflows for Photonome

These workflows replace Replicate API calls with local ComfyUI inference running on DGX Spark.

## Required Models

Place these in your ComfyUI model directories:

| File | Directory | Download |
|------|-----------|----------|
| `flux1-dev.safetensors` | `models/unet/` | [Hugging Face](https://huggingface.co/black-forest-labs/FLUX.1-dev) |
| `ae.safetensors` | `models/vae/` | [Hugging Face](https://huggingface.co/black-forest-labs/FLUX.1-dev) |
| `t5xxl_fp16.safetensors` | `models/clip/` | [Hugging Face](https://huggingface.co/comfyanonymous/flux_text_encoders) |
| `clip_l.safetensors` | `models/clip/` | [Hugging Face](https://huggingface.co/comfyanonymous/flux_text_encoders) |
| `user_lora.safetensors` | `models/loras/` | Generated by training workflow |

> On DGX Spark with 80GB VRAM, you can use `flux1-dev.safetensors` at full `fp16` precision.
> Set `weight_dtype` to `fp8_e4m3fn` to halve VRAM usage if running multiple concurrent jobs.

## Workflow Map (Replicate → ComfyUI)

| Original Feature | Replicate Call | ComfyUI Workflow |
|-----------------|---------------|-----------------|
| Custom Styling / Prompt Families | `ostris/flux-dev-lora-trainer` prediction | `flux_txt2img_lora.json` |
| Magic Touch (face enhancement) | Prediction with `image` + `mask` params | `flux_inpaint_lora.json` |
| Anime Transformation | OpenAI `gpt-image-1` edit | `flux_anime_style.json` |
| Style Transfer / img2img | Prediction with `image` + `prompt_strength=0.8` | `flux_img2img_lora.json` |
| Base generation (no LoRA) | Direct Flux Dev prediction | `flux_txt2img_base.json` |
| LoRA Training | `replicate/fast-flux-trainer` training job | `flux_lora_training_cli.sh` |

## Workflow Details

### `flux_txt2img_lora.json` — Text-to-Image with Personal LoRA
Main generation workflow. Equivalent to the Replicate prediction with a trained model version.

**Key parameters to swap per-request:**
- Node `5` → `t5xxl`: the full generation prompt (keep `TOK` as the trigger word)
- Node `5` → `clip_l`: short summary of the prompt
- Node `5` → `guidance`: 3.5 default (range 1–5)
- Node `7` → `width`/`height`: 1024×1024 default
- Node `8` → `seed`: random per generation
- Node `8` → `steps`: 28 default (reduce to 20 for speed)
- Node `4` → `lora_name`: user's trained LoRA filename
- Node `4` → `strength_model`: 1.0 default (`lora_scale` in Replicate)

### `flux_txt2img_base.json` — Text-to-Image (No LoRA)
For prompt families that don't require a personal LoRA.

### `flux_img2img_lora.json` — Image-to-Image with LoRA
Style transfer / pose transfer. Equivalent to Replicate prediction with `image` + `prompt_strength=0.8`.

**Key parameters:**
- Node `5` → upload the input image path
- Node `9` → `denoise`: 0.8 default (`prompt_strength` in Replicate; lower = more original image preserved)

### `flux_inpaint_lora.json` — Inpainting for Magic Touch
Face enhancement with face mask. Replaces Replicate's `image` + `mask` inpainting.

**Key parameters:**
- Node `5` → upload the original photo
- Node `6` → upload the face mask PNG (white = region to regenerate)
- Node `9` → `t5xxl`: use gender-specific prompt (see below)
- Node `11` → `denoise`: 0.85 default

Gender-specific prompts (same as original app):
- Male: `"A portrait ultra-realistic photo of TOK who is a handsome, good looking male. Enhance the facial features while maintaining photorealistic quality."`
- Female: `"A portrait ultra-realistic photo of TOK who is a beautiful, good looking female. Enhance the facial features while maintaining photorealistic quality."`

Node `13` (`ImageCompositeMasked`) composites the generated face back onto the original image, preserving the background — equivalent to inpainting behavior.

### `flux_anime_style.json` — Anime Style Transformation
Replaces OpenAI `gpt-image-1` and Gemini anime generation.

**Style prompts** are embedded in `_style_prompts` at the top of the JSON. Swap node `7` values per selected style:

| Style | `clip_l` | Notes |
|-------|---------|-------|
| Studio Ghibli | `"Studio Ghibli anime"` | `denoise=0.75` |
| Pixar | `"Pixar 3D animation"` | increase `denoise` to 0.8 |
| Rick and Morty | `"Rick and Morty cartoon"` | `denoise=0.75` |
| Walt Disney | `"Walt Disney animation"` | `denoise=0.75` |
| Looney Tunes | `"Looney Tunes cartoon"` | `denoise=0.7` |
| Kawaii Anime | `"kawaii anime chibi"` | `denoise=0.8` |

LoRA strength is set to 0.8 (lower than t2i) to balance identity preservation vs. style transfer.

### `flux_lora_training_cli.sh` — LoRA Training
Replaces `replicate/fast-flux-trainer`. Uses [ai-toolkit](https://github.com/ostris/ai-toolkit) directly.

```bash
./flux_lora_training_cli.sh /path/to/user_photos user123_lora 1000
```

- Default 1000 steps (same as fast-flux-trainer default)
- Saves intermediate checkpoints every 250 steps
- Output: `{COMFYUI_LORAS_DIR}/{output_name}.safetensors`

Set env vars to customize paths:
```bash
export AI_TOOLKIT_DIR=/opt/ai-toolkit
export COMFYUI_LORAS_DIR=/opt/ComfyUI/models/loras
export FLUX_MODEL_DIR=/opt/ComfyUI/models/unet
```

## ComfyUI API Usage (for the React Native backend)

Trigger generation programmatically via ComfyUI's HTTP API:

```python
import json, requests, random

COMFYUI_URL = "http://localhost:8188"

def run_workflow(workflow_path: str, overrides: dict) -> str:
    with open(workflow_path) as f:
        workflow = json.load(f)

    # Apply per-request overrides
    for node_id, node_inputs in overrides.items():
        workflow[node_id]["inputs"].update(node_inputs)

    # Randomize seed
    workflow["8"]["inputs"]["seed"] = random.randint(0, 2**32)

    resp = requests.post(f"{COMFYUI_URL}/prompt", json={"prompt": workflow})
    return resp.json()["prompt_id"]

# Example: text-to-image with user LoRA
prompt_id = run_workflow("flux_txt2img_lora.json", {
    "4": {"lora_name": "user123_lora.safetensors"},
    "5": {"t5xxl": "A portrait photo of TOK wearing a business suit, professional headshot"},
    "7": {"width": 1024, "height": 1024},
})
```

Poll `GET /history/{prompt_id}` for completion and retrieve the output image path.
